## Installation
Window > Package Manger > button (+) on the top left > add package with git url > https://github.com/TheTimeSweeper/HenryEditorTools.git

- Requires a thunderkit import of RoR2 in your project. 
  - See import guide for henry projects here [here](https://github.com/ArcPh1r3/HenryTutorial/wiki/Using-RoR2-Scripts-in-Unity-Editor-(Thunderkit-Import))
  - See more information about using ror2 scripts in editor [here](https://risk-of-thunder.github.io/R2Wiki/Mod-Creation/Unity-Editor-Usage/Using-MonoBehaviour-Scripts-in-Editor/).
